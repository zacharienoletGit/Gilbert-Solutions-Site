# lead-generation-security

L'utilisateur visiteur doit pouvoir décrire une tâche, comprendre pourquoi ses données sont demandées, recevoir une confirmation et savoir que Gilbert répondra. Le minimum collecté : nom, courriel professionnel, entreprise facultative, outils et description de la tâche. Succès : une demande valide est livrée sans exposer de clé ni créer une promesse commerciale imprécise.
