# lead-generation-security

Menaces principales : robots, abus de formulaire, collecte excessive, injection de contenu et fuite de clé. Contrôles : Turnstile, honeypot, KV rate limit, validation de schéma, limites de longueur, texte brut, secrets Cloudflare, politique CSP et Permissions-Policy. Le formulaire ne stocke pas de données dans le site; Resend traite l'envoi selon la politique publiée.
